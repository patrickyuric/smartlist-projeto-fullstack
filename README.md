## 🚀 Sobre o Projeto
O SmartList é um aplicativo simples e funcional de Lista de Compras projetado para introduzir o desenvolvimento Full Stack passo a passo. Ao longo de 7 semanas, os alunos construirão desde a interface web até o consumo de dados em um aplicativo móvel, passando pela criação de uma API e um banco de dados local. 

O foco deste repositório é garantir que todos tenham uma experiência prática, visual e rápida na construção do seu primeiro sistema completo.

## 🛠️ Stack Tecnológica
* **Front-end Web:** HTML5, CSS3, JavaScript e Bootstrap
* **Back-end:** Node.js com Express
* **Banco de Dados:** SQLite
* **Mobile:** React Native (via Expo)
